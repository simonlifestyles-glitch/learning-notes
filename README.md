每個主題建議按照以下格式記錄：

```markdown

## 是什麼？

## 為什麼重要？
這個概念解決了什麼問題？

## 核心重點
- 重點一
- 重點二
- 重點三

## 程式碼範例
用程式碼示範這個概念

## 我的疑問

## 參考資源
- 連結一
- 連結二
```

## 💡 學習原則

1. **先求懂，再求深** — 每個概念先理解「是什麼」和「為什麼」，細節之後再補
2. **動手寫筆記** — 用自己的話重新解釋，才是真正學會
3. **多問問題** — 不懂就問，沒有笨問題
4. **建立連結** — 把新知識和已知的事物連結，幫助記憶
